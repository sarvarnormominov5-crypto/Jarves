JARVES AI

A futuristic personal AI assistant inspired by advanced science-fiction technology.

Features

* AI-powered chat
* Voice input and spoken responses
* Uzbek, Russian, and English support
* Mobile-first responsive interface
* Personal notes and reminders
* Futuristic dark interface with cyan-blue effects

Technology

* React
* Vite
* CSS
* Netlify Functions
* AI API integration

Project Status

Early development. Features listed above are planned and will be implemented step by step.

Security

API keys and private credentials must be stored securely in server-side environment variables. Never publish them in frontend code or GitHub.
